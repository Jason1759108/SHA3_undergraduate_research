# Legacy SECDED source archive

These four files retain the previous (72,64) ECC implementation for reference
and the standalone Hamming test. They are excluded from the active SHA3 build.

The complete runnable SECDED baseline (including theta, chi, scheduler, top,
FT patterns and both lane / 1600-bit synthesis scripts) is Git commit
`0798e0b9ed8ba1b73a2cdd427b2441c755fb4903`.
Do not mix the old overlays with the new 64-bit raw-data parity interface.
