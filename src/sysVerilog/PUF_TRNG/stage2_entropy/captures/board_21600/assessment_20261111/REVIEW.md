# 百萬點原始熵源評估（2026-11-11）

## 本次結論

目前硬體版本的第一輪原始來源量測與資料統計評估已完成：1000 批、1024000 個八路聯合樣本，完整性核對通過。NIST 非 IID 統計估計與候選 RO 重啟測試完成，九種資料表示均通過本次重啟測試。這不是來源的完整標準符合性或 TRNG 認證；尚未選定可保證使用的熵信用。

八路聯合資料的初估及重啟後保留值約為 **6.646975 bits/八路樣本**。一個樣本是一個 byte，包含同時取樣的八個通道；不是每個位元都有 6.65 bits，也不是 6.65 bits 的無條件物理下界。

單通道樣本是一個 0/1 值；單通道估計不能相加代替八路聯合評估。對八路資料，工具同時估計聯合符號與位元串，最終取保守者；本次聯合符號 LZ78Y 預測估計約 6.647，小於位元串估計折算後約 7.162。數字不是 SHA3 可直接消耗的保證信用，還缺來源模型與適用範圍的支持。

## 工具與可信度檢查

來源：[NIST SP800-90B_EntropyAssessment](https://github.com/usnistgov/SP800-90B_EntropyAssessment)，版本標示 1.1.8，固定 commit `87c104d0ed4cbc96103e7b8b38d6f2c7e0a6b289`。感謝 NIST 提供評估實作；原始授權與免責聲明保留在 references 內。

使用本機 MinGW GCC 建置。非 IID 程式使用未修改的 NIST 估計程式碼；11 組官方參考 self-test 的估計欄位均符合，採官方比較腳本的數值比較方式與 1e-10 門檻。最大差異為 1.0080825063596421e-13。所有命令、時間、完整日誌及版本見 nist_results 與 assessment_summary.json。

原始重啟工具要求 Linux /dev/urandom，Windows 首次執行因此退出，這是工具環境錯誤，不是來源測試失敗。原始錯誤日誌保留。Windows 相容版本只在獨立來源副本中將模擬器 seed() 改讀 OpenSSL RAND_bytes；沒有更改熵估計、模擬演算法、門檻或 FPGA 資料。這些電腦亂數只用於估計重啟檢查門檻，沒有混進受測資料。修改內容記錄於 build/nist_native/windows_seed.patch；如需正式審查可在官方支援的 Linux 環境交叉確認。

相容版本另以官方隨機參考資料作正向控制，通過；將同一列重複 1000 次作負向控制，正確拒絕（X_max=1000，cutoff=103）。之後才對原始 FPGA 資料執行重啟評估。九個實際資料測試均未改門檻追求 PASS。

## 為什麼還不是完整 TRNG

工具估計的是本次資料的統計不可預測程度。仍須說明 RO 抖動機制、來源重啟/暖機與資料可用狀態，限定操作條件，並建立保守熵信用。現有卡死/看門狗保護不足以直接宣稱已具備完整的啟動與運行健康監測。尚未接 SHA3，也尚未定義累積量、隨機輸出有效訊號與故障時停止供應。

本次不再要求多收一輪相同資料來替代這些工作。下一階段依 [階段完成條件](../../../docs/ENTROPY_STAGE_EXIT_CRITERIA.md) 執行：三項交付條件、兩段明確上板驗收，失敗時針對原因修正。這是限定範圍的研究原型規劃，不是完整標準認證測試清單。
