# 開發歷程封存

此目錄不參與正式模擬/合成。

- `legacy_ro_integration/`：整理前原src/puf的來源、00/01/02、文件、少量證據；原檔名保留，SNAPSHOT_MANIFEST記錄hash。未含.build/快取/大型波形，完整原目錄另有外部備份。
- `ro8/`、`ro32/`、`ro320/`：早期獨立RO診斷報告，適用各自舊版bitstream。不要將它們的量測次數加總成最終PUF的驗證總數。

舊README中的「未上板」「RO只是模板」、舊syn.tcl及舊模組名稱是當時的事實，不是現在正式版本的操作說明。請回到根README使用新版入口。
