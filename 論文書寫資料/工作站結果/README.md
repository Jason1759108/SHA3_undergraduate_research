# 工作站精簡結果

`2026-11-04_四版10ns/` 是使用者上傳 `compact_results_20261104_170428.zip` 後擷取的八個小檔案。每版的 `rtl_latest.json` 記錄完整 01 RTL 的 PASS、執行來源指紋及 4096 byte 訊息週期；`results/sweep/sweep_summary.csv` 記錄 10 ns 02 合成數字、完整 SHA3 的 P/T 和 03 gate 結果。

此處不保存製程庫、netlist、SDF 或大型工具工作目錄。四版摘要見 `2026-11-04_四版10ns/四版10ns摘要.csv`。原始 zip 在使用者下載目錄，這裡保存已解出的精簡結果。
