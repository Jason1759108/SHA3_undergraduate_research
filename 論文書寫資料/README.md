## 組員閱讀順序與目前狀態

1. 先看 [RTL／合成工具架構](./分工說明與模板/論文_RTL與合成工具架構說明.md)，了解四版、檔案與新舊流程。
2. 操作時看 [工作站指南](./分工說明與模板/工作站操作與資料說明.md)。正式來源在四版本程式，sha3_paper_complete.zip 是相同內容的傳輸包，不另維護補丁。
3. 寫作看共同 Phase、PersonA／PersonB 手冊與英文 Word 骨架。Word 是刻意保留的待寫模板，不是損壞／待刪檔案。

本資料夾尚未追蹤時，需明確加入 Git 才會包含在提交中。倉庫 others/ 另有既存未追蹤檔案；本次整理未擅自刪除或移動它們。新忽略規則只排除執行目錄中的自動產物，不會排除整理好的參考證據或唯一完整版 ZIP。
