# 四版本專題資料

目前專案用於大學部專題發表，沒有安排論文撰寫。`四版本程式/` 是四版正式工作站 overlay 和唯一的傳輸 ZIP；`工作站結果/2026-11-04_四版10ns/` 存四版 01 RTL 記錄與 10 ns 02／03 CSV。`參考資料/`、`分工說明與模板/`、`personA工作空間/`、`personB工作空間/`、`論文定稿/` 保留舊有內容作參考，並非現行工作清單。

四版 2026-11-04 工作站結果：01 RTL 均 `PASS`，10 ns 02 合成均 `OK`，03 均 `PASS_WITH_SDF_WARNING`，且 CSV 均記錄沒有 timing violation。03 有 SDF 警告，不能描述成無警告通過。所有功耗為 DC 估計值；完整 SHA3 P/T 使用 4096 byte 訊息的 7668 cycles，舊 P/T 欄維持 1088 bits／240 cycles 的口徑。詳細數字見 `工作站結果/2026-11-04_四版10ns/四版10ns摘要.csv`。

原始 `src/sysVerilog` 的 V3 00/01/02 已同步正式 V3 檔案；為支援原工作站 `SHA3` 專案名稱，00/02 的兩個 Python 控制檔增加名稱相容處理。`src/sysVerilog/03_GATE/README_10NS_GATE.md` 說明如何在原專案跑同樣的流程。獨立 `SHA3` 名稱的流程尚未在工作站重跑；已驗證的四版以 `四版本程式/` 和結果資料為準。密集掃頻尚未進行。
