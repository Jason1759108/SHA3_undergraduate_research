# 四版本專題資料

目前專案以大學部專題發表為主；若之後恢復論文撰寫，使用 [共同 Phase 與分工](./分工說明與模板/論文_共同Phase排程與分工.md)、[Person A 手冊](./分工說明與模板/論文_PersonA工作手冊.md)、[Person B 手冊](./分工說明與模板/論文_PersonB工作手冊.md)及[英文 Word 骨架](./分工說明與模板/論文_寫作架構範本.docx)。此可選路線只比較**四版共同 10 ns**，主要研究問題是 V1／V2 的 SECDED 粒度；V3 是不同保護能力的延伸策略。不把掃頻當作寫作前提。

`四版本程式/` 是四版正式工作站 overlay 和傳輸 ZIP；`工作站結果/2026-11-04_四版10ns/` 存四版 01 RTL 記錄與 10 ns 02／03 CSV。現行資料口徑及重現方式見 [固定 10 ns 資料說明](./分工說明與模板/工作站操作與資料說明.md)。`參考資料/` 保存文獻與歷史紀錄；個人工作空間及 `論文定稿/` 保留給未來寫作。其他舊版掃頻、Tcl 恢復及除錯指南是歷史資料，不作此路線操作指令。

四版 2026-11-04 工作站結果：01 RTL 均 `PASS`，10 ns 02 合成均 `OK`，03 均 `PASS_WITH_SDF_WARNING`，且 CSV 均記錄沒有 timing violation。03 有 SDF 警告，不能描述成無警告通過。所有功耗為 DC 估計值；完整 SHA3 P/T 使用 4096 byte 訊息的 7668 cycles，舊 P/T 欄維持 1088 bits／240 cycles 的口徑。詳細數字見 `工作站結果/2026-11-04_四版10ns/四版10ns摘要.csv`。

原始 `src/sysVerilog` 的 V3 00/01/02 已同步正式 V3 檔案；為支援原工作站 `SHA3` 專案名稱，00/02 的兩個 Python 控制檔增加名稱相容處理。`src/sysVerilog/03_GATE/README_10NS_GATE.md` 說明如何在原專案跑同樣的流程。獨立 `SHA3` 名稱的流程尚未在工作站重跑；已驗證的四版以 `四版本程式/` 和結果資料為準。密集掃頻未進行，也不屬可選論文路線的必備工作。
