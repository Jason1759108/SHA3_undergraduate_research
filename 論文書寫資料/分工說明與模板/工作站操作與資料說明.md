## 2 本論文的固定比較條件

主表只比較同一製程、工具流程及 **10 ns** 下的整個 SHA3 top。先依正式四版 `02_SYN/syn.tcl`、`run_sweep.sh` 與 CSV 記錄共用的合成設定；若未保存某項 setup／report，明寫「未保存／未核對」。`status=OK` 是這個原腳本的合成結果，不能自行擴張為所有 DRC、所有 hold check 或物理 signoff 都通過。

四版量測欄位須同口徑：

| 欄位 | 寫法與界線 |
| --- | --- |
| `total_cell_area` | 整個 SHA3 top 的合成 cell area；面積單位要核對 library／原報告後才標 µm² |
| `total_power_mw` | DC 估計的整個 SHA3 功耗；沒有 SAIF 或實測活動波形 |
| `worst_slack_ns` | 10 ns 這個設計點的報表值；V1、V2 顯示 0.00，不是最高頻率或裕量充分的證據 |
| `e2e_cycles_4096B` | 01 RTL 量到的 4096-byte 正常訊息總週期；四版都是 7668 |
| `full_sha3_throughput_gbps` | `32768 / (7668 × 10)` = 約 0.427334 Gbps |
| `full_sha3_estimated_p_over_t_pj_per_bit` | `total_power_mw / full_sha3_throughput_gbps`；mW/Gbps = pJ/bit，是估計 P/T，不是實測能量 |
| 舊 `throughput_gbps`、`energy_per_bit_pj` | `1088 / (240 × 10)` 與 `total_power_mw / throughput_gbps`；分母用核心理論拍數，但分子仍是整顆 SHA3 功耗，只作舊口徑對照 |
| `standalone_core_cycles=241` | 01 RTL core reference-vector TB 的週期。沒有獨立 core 合成、功耗或面積，不能算 `P_core/T_core` |

主要量化比較是 V1→V2。按現有 CSV，V2 面積比 V1 約低 1.9%，完整 SHA3 的估計 P/T 約低 4.2%。V3 另做不同保護能力下的成本取捨；不能稱與 V1／V2 等強度防錯。V0 用於算保護成本增量。所有百分比的分母須在表註寫清楚。

## 3 論文可寫與不可寫的結論

- 可寫：四版在這次 01 RTL suite 通過；10 ns 02 `OK`；03 正常功能在帶 SDF、仍有警告的條件下通過，沒有記錄到 timing violation。V1／V2 在相同 10 ns 的成本差、已編寫 PATTERN 所涵蓋的故障類別與保護組織差異。
- 不寫：最佳操作點、精確 Fmax、跨頻率優勢、core 合成 PPA、故障恢復能量、逐模組成本、critical-path 成因、post-layout signoff、任意故障 100% coverage、已完成實體晶片驗證。
- `rtl_latest.json` 沒有逐案 digest、額外拍或 fault coverage 母體；圖表可引用 PATTERN 的案例設計與 suite PASS，但不能把未保存的逐案觀測值填成數字。V3 parity 的偶數翻轉盲點必須寫入限制。
- ArchHC 為 FPGA 與不同架構／吞吐口徑的研究動機，不能直接用其 LUT 或 Mbps 與本組 ASIC 數字排名。

## 4 需要重現時的最少工作站流程

只在來源變更、結果遺失或老師要求重測時使用。每版先 `build <版本名稱>`，再把正式 ZIP 中該版同名 overlay 複製到 build 專案；詳見 `四版本程式/PROJECT_10NS_GUIDE.md`。在四版專案的上層執行：

```bash
bash check_serial320_10ns.sh
python collect_compact_results.py compact_results_new.zip
```

前一行逐版執行完整 01、單一 10 ns 02 與對應 03；以 `[ALL_FOUR_10NS_PASS]` 及四列 CSV 的 02／03 狀態判斷結果。後一行只打包四份 `rtl_latest.json` 和四份 CSV。正式流程在寫入 CSV 後清除暫存 netlist、SDF 與報告；**不需要長期保留每個週期的工具目錄**。本機沒有 VCS、Design Compiler 與製程庫，本文不能代表在本機重做了 EDA 實驗。

其他名為「原始四版掃頻／Tcl 恢復／合成重跑」的舊指南記錄了歷史除錯過程，**不作本版論文操作指令**。
