# SHA3-256 互動教學

## 直接開啟

使用 Chrome 或 Edge 開啟 `index.html` 即可操作，不需要 Codex。

## 使用本地網址

1. 雙擊 `start.cmd`，保持該視窗開啟。
2. 在瀏覽器開啟 http://127.0.0.1:8765/ 。
3. 在啟動視窗按 Ctrl+C 可停止服務。

伺服器只監聽本機。啟動程式會優先使用系統的 Node.js，再嘗試這台電腦的 Codex 內附 Node.js；不需要安裝 npm 套件。在其他電腦上可直接開啟 HTML，或安裝 Node.js 後執行 `node server.cjs`。

拖曳立體陣列旋轉視角，點選柱體查看 lane。可輸入字串、逐步播放或跳到指定輪次。x、y 軸及 A[0,0] 起點會隨視角旋轉。

此目錄的 `index.html` 是對話中互動動畫的獨立匯出版本；之後修改對話版本不會自動同步到此檔案。
